# Part 5 — LLMs & prompting strategies

> Part 5 of **[Tokens to Agents](../../README.md)** — the foundations of agentic AI, built from scratch.

**The input is now part of the model.**

Once a model is frozen behind an API, the prompt is the only surface left. This part measures how much that surface actually moves the result — and finds that the received wisdom does not always hold.

Covers: zero/one/few-shot in-context learning, chain-of-thought, a controlled prompt-perturbation study across two model families, decoding parameters, and a retrieval-augmented generation pipeline with its failure modes.
