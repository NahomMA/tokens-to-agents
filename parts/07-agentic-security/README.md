# Part 7 — Agentic AI security

> Part 7 of **[Tokens to Agents](../../README.md)** — the foundations of agentic AI, built from scratch.

**Now break it.**

The series ends where the research begins: an agent guarded by layered LLM defences, attacked systematically, and measured. Each defence layer is ablated so its real contribution is visible rather than assumed.

Covers: a layered defence pipeline (input scanning, output scanning, adjudication), a red-team prompt corpus spanning direct extraction, instruction override, partial completion and side-channel phrasing, an ablation over defence configurations, and the cost/reliability tradeoffs of LLM-as-a-judge.

Published as defensive research. Attack prompts are included as evaluation material for building defences.
